# Improve an Existing Website

1. Inspect the repository, current branch, project structure, and implementation before editing.
2. Read the project brief and relevant Website Factory skills.
3. Identify the requested change and the components it may affect.
4. Preserve working behavior and established design decisions unless explicitly asked to replace them.
5. Make the smallest coherent set of changes; avoid opportunistic rewrites.
6. Keep the Vanilla HTML/CSS/JavaScript policy. Do not introduce a framework.
7. Test changed behavior at relevant viewport sizes and check console output.
8. Summarize changed files, validation performed, and remaining limitations.
9. Commit to a feature branch or user-specified branch. Do not merge without authorization.
