# Generate a Website

1. Load `skills/core/website-factory/SKILL.md`.
2. Resolve audience, objective, offer, content, proof, CTA, constraints, and deployment needs.
3. Load relevant page-type and capability skills.
4. Inspect supplied references; use Reference DNA / Distinctive Patterns prompts when useful.
5. Read `design-intelligence/selection/design-selection.md`; choose a visual direction and retrieve a coherent set of relevant patterns. Record selected IDs, rationale, rejected alternatives, and assumptions.
6. Define the visual thesis, tokens, section narrative, and asset direction before coding.
7. Start from `templates/vanilla-static/` unless another static structure is justified.
8. Implement semantic HTML, CSS, and Vanilla JavaScript. Add Alpine.js, GSAP, or Three.js only when justified.
9. Verify interactions and remove fake/placeholder actions.
10. Follow `workflows/review.md`.
11. Create a dedicated GitHub repository and commit source plus README.
12. Follow `workflows/deploy.md` when Vercel is connected.

Generated client projects do not belong inside this skills repository.
