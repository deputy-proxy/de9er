# Generate a Website

1. Load `skills/core/website-factory/SKILL.md`.
2. Resolve audience, objective, offer, content, proof, CTA, constraints, and deployment needs.
3. Load relevant page-type and capability skills.
4. Inspect supplied references; use Reference DNA / Distinctive Patterns prompts when useful.
5. Define the visual thesis, tokens, section narrative, and asset direction before coding.
6. Start from `templates/vanilla-static/` unless another static structure is justified.
7. Implement semantic HTML, CSS, and Vanilla JavaScript. Add Alpine.js, GSAP, or Three.js only when justified.
8. Verify interactions and remove fake/placeholder actions.
9. Follow `workflows/review.md`.
10. Create a dedicated GitHub repository and commit source plus README.
11. Follow `workflows/deploy.md` when Vercel is connected.

Generated client projects do not belong inside this skills repository.
