# Initial hero pattern collection

Ten source-independent hero patterns with structured records and standalone Vanilla HTML/CSS demonstrations.

| Pattern | Design principle | Demo |
|---|---|---|
| Editorial type-led | Let the proposition lead when language is the strongest asset. | [Open](../../examples/editorial-type-led/index.html) |
| Split-screen value | Separate explanation from one focused demonstration. | [Open](../../examples/split-screen-value/index.html) |
| Product interface stage | Show a representative interface to make software tangible. | [Open](../../examples/product-ui-stage/index.html) |
| Immersive image overlay | Let one relevant image establish context while protecting text legibility. | [Open](../../examples/immersive-image-overlay/index.html) |
| Asymmetric art-directed | Use controlled imbalance to create a distinctive visual rhythm. | [Open](../../examples/asymmetric-art-directed/index.html) |
| Bento feature mosaic | Use unequal tiles to communicate related capabilities with hierarchy. | [Open](../../examples/bento-feature-mosaic/index.html) |
| Proof-first | Put real, attributable evidence beside the promise. | [Open](../../examples/proof-first-hero/index.html) |
| Conversion form-first | Place a minimal form beside a clear proposition when intent is high. | [Open](../../examples/conversion-form-first/index.html) |
| Typographic brand statement | Let a concise, distinctive brand statement become the composition. | [Open](../../examples/typographic-brand-statement/index.html) |
| Interactive product preview | Demonstrate one meaningful product behavior directly. | [Open](../../examples/interactive-product-preview/index.html) |

Each pattern includes suitability and avoid-when guidance. The examples use original placeholder copy and CSS-built visuals; they are not reproductions of source websites.

## Status

Records and examples are marked `implemented`. Browser, responsive, keyboard, contrast, and assistive-technology validation remains outstanding. See [review notes](../../validation/hero-patterns-review.md).
