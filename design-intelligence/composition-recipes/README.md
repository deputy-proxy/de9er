# Composition recipes

A composition recipe describes a coherent page-level arrangement of patterns. It is not a wireframe to apply blindly.

Each recipe should include:
- recipe ID and intent
- audience and conversion/content objective
- visual direction assumptions
- ordered sections and their purpose
- selected pattern IDs and why they work together
- content requirements and dependencies
- responsive changes
- accessibility and performance considerations
- alternatives and conditions where the recipe should not be used

Recipes must explain the logic connecting sections. Avoid defaulting to a hero followed by repeated three-card grids. A recipe should be adaptable to real content and should allow sections to be removed when they do not serve the page.
