# Pattern demonstration template

Copy this directory to `design-intelligence/examples/{pattern-id}/` and replace the placeholder content.

- Open `index.html` directly in a browser.
- Uses the repository Tailwind CSS build; run `npm ci && npm run build:css` from the repository root before previewing.
- Keep markup semantic and content realistic but fictional.
- Use Tailwind utilities for structure and styling. Add local CSS only for bespoke artwork or effects; do not add external dependencies by default.
- Test narrow viewports, keyboard navigation, and reduced motion.
