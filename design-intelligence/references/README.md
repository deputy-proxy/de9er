# Reference provenance

This directory contains lightweight reference records or indexes that point to source websites and captured evidence. It is not an asset archive.

For each source, record:
- stable reference ID and name
- canonical URL
- capture date and available viewport(s)
- evidence actually collected (screenshots, DOM, CSS, assets, interaction observations)
- known limitations
- related pattern IDs
- attribution and originality notes

Keep source evidence separate from reusable patterns. A reference can inspire multiple patterns, and a pattern can be informed by multiple references.

Do not store copied website copy, proprietary source assets, credentials, or unnecessary personal data. Use links and concise observations instead.
