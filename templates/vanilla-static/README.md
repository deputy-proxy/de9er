# Vanilla Static Template

A zero-build starter for static websites. Copy this directory into a new project.

- `index.html`: semantic page shell
- `assets/css/styles.css`: tokens, layout, responsive styles
- `assets/js/main.js`: progressive-enhancement entry point

No framework, bundler, or package manager is required. Add Alpine.js, GSAP, or Three.js only when needed; pin CDN versions and provide fallbacks. Replace all sample content and metadata, verify all actions, and deploy as a static site.
