# SaaS Website

Use when explaining and selling a software product, platform, or subscription service.

## Information architecture
Select what is relevant: product promise; target customer; workflow/how it works; capabilities tied to outcomes; authentic product UI; use cases; integrations; security/trust; pricing; customer evidence; FAQ; onboarding CTA.

## Design guidance
Show the product, not only abstract gradients or decorative dashboard mockups. Use real screenshots where available. Label illustrative mock UI as illustrative. Explain what users accomplish, how the product fits their workflow, and what happens after signup.

Never invent integrations, certifications, security guarantees, customer counts, pricing, or testimonials.
