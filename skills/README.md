# Skills

Load the core Website Factory skill first, then only the modules relevant to the brief.

- core/: orchestration and shared standards.
- page-types/: information architecture and content patterns for different site purposes.
- design-systems/: visual directions and design-language guidance.
- capabilities/: focused implementation guidance for motion, 3D, accessibility and performance.

## Three.js / WebGL
The Three.js capability is now a mandatory three-stage workflow:
1. Art direction and reference analysis: design-intelligence/skills/webgl-art-direction/SKILL.md
2. Engineering: design-intelligence/skills/threejs-engineering/SKILL.md
3. Visual review and evidence: design-intelligence/skills/threejs-visual-review/SKILL.md

Use design-intelligence/references/webgl-research.md for curated galleries and case-study lessons. Do not equate a functioning renderer with a successful design. Vanilla HTML/CSS/JavaScript remains the default implementation policy; React Three Fiber and build tooling are not defaults.

Skills must be specific, actionable and evidence-based. Separate mandatory constraints from optional suggestions. Do not create near-duplicate prompts.
