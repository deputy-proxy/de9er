# Design Systems and Visual Directions

A design system is a coherent set of visual rules, not a prebuilt skin. Select direction from the brand, audience, content, and reference evidence.

Initial directions to develop:
- **Minimalist:** restraint, hierarchy, purposeful whitespace.
- **Editorial:** typographic voice, deliberate grids, long-form rhythm, image-led storytelling.
- **Luxury:** materiality, precise typography, controlled pacing, high-quality imagery.
- **Playful:** expressive color and shape, lively but legible typography.
- **Brutalist:** raw structure, strong contrast, visible grid, intentional typographic tension.

For every project, define actual tokens and usage rules. Never assume industry dictates style. Use `.chatgpt/` reference prompts to extract evidence and principles. Record human preferences separately; never infer them from a supplied URL.
